

Project Limitations
This customer support assistant was developed without a trainer-provided LLM API key.

Ticket classification currently uses local keyword rules.

Document Q&A uses local retrieval and keyword matching.

Chat tool selection uses local rules for the sample CRM and order scenarios.

The application does not claim to provide real LLM-generated responses.

A configured LLM API can be integrated later to support model-generated answers and model-based tool selection.

Testing
The local test script reported 10/10 basic checks passing. These checks verify expected response behavior; they do not establish full factual accuracy or real LLM functionality.
